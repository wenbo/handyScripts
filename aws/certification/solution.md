一、学习资源
1. Udemy 小黄老师课程（Stephane Maarek）
我看了一遍，对初学友好，帮助理解了整个 AWS 架构，比如 ALB、NAT Gateway 应该放在哪一层、和 VPC 如何配合等，图解得很直观。
如常见三层架构：Route 53 + CloudFront 作为入口 → 流量进入 ALB → 后端是 Auto Scaling 的 EC2 群组 → 数据层用 RDS 或 DynamoDB，静态资源放 S3，这类组合在考试中出得非常多。
2. Udemy 六套模拟题
看完视频课就做了，感觉很难，或者说风格和实际考试差距蛮大，六套题我一套都没超过 65% 不过对理解服务之间的配合还是有帮助的。
3. Pingt 模拟题库(不会日语也可以用谷歌翻译)
所有题全刷完了，相对基础一些，但题型覆盖广。很多题是关于服务的“单点知识”，比如 S3 存储类型、EBS 卷类型选型、Lambda 搭 API Gateway，很推荐。
4. ExamTopics 真题
传说中的真题网站。1019道题我也刷完了，因为是真题，所以难度和类型就和考场出现的完全同水平。据说运气好会遇到很多原题照搬，我大概碰到 4～5 题几乎一模一样，而这几题都基本是900号题以后出现的，所以如果时间紧或想速通，建议倒着刷，效率更高。
	
二、Tips
1.记住所有服务的关键词，可以大大节省时间。如图3、4。
2.AWS 环境有免费的12个月体验，想试着操作的话记得提前关掉自动续费。
3. 题库我淘宝买的PDF，不好用。后来就去官网刷，前200题是免费的，后面用 “ExamTopics AWS SAA C03 questions #” 搜题就可以免费看所有题目和别人的讨论。
4.如果方便，建议去线下考，稳定省心，不用担心突发状况直接考不了试等。(是谁有突发状况我不说😇)
	
如果选择在家考，一定要提前做好网络和系统测试！一旦出现任何问题，立刻联系官方，通常是可以申请重新安排考试的！
