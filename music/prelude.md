はい。バッハの**《平均律クラヴィーア曲集 第1巻 第1番 プレリュード ハ長調 BWV 846》**ですね。

### 🎹 5小節目のコードは「Am（Aマイナー）」です

5小節目の音をコードとしてまとめると、

**C – E – A – E – A**

となっているので、基本的には

**Am = A・C・E**

です。C長調のローマ数字では **vi（第6音上のマイナーコード）** です。 ([Music: Practice & Theory Stack Exchange][1])

ただし、ここが面白いところです。

### 5～8小節を見ると

| 小節 | コード       | 役割  |
| -- | --------- | --- |
| 5  | **Am**    | vi  |
| 6  | **D7**    | V/V |
| 7  | **G**     | V   |
| 8  | **Cmaj7** | I   |

つまり、

**Am → D7 → G → C**

という流れになっています。 ([Music: Practice & Theory Stack Exchange][1])

これは初心者がコード進行を勉強するには非常に良い例です。

特に **D7 → G** は、

> 「Gに行きたいので、その直前にD7を置く」

という**セカンダリードミナント**です。

そして、5小節目のAmから見ると、

**Am → D7 → G → C**

と、ベース音が

**A → D → G → C**

と進んでいきます。

実は、ここは「カノン」のコード進行を勉強するのとは少し違って、**バッハがどうやってコードを次々につなげているか**を学ぶのに非常に良い場所です。

もしよければ次に、**「プレリュードBWV846の1～10小節を、初心者向けに『このコードから次のコードへなぜ行くのか』まで含めて説明」**できます。これはかなり勉強になります。

もちろんです。ここは**「1小節＝1つのコード」**として見ると、一気に分かりやすくなります。

まず訂正があります。先ほど私が「5小節目はAm」と説明したのは、コード名を簡略化しすぎました。より正確には**Am/C（Aマイナーの第1転回形）**です。6小節目も **D7/C** と見るのが一般的です。1〜10小節の代表的な分析は、次のようになります。([Music: Practice & Theory Stack Exchange][1])

## 🎹 まず1〜10小節のコード

| 小節 | コード         | C長調での役割 | 初心者向けの理解              |
| -: | ----------- | ------- | --------------------- |
|  1 | **C**       | I       | 家に到着                  |
|  2 | **Dm7/C**   | ii⁷     | 少し動き始める               |
|  3 | **G/B**     | V       | Cに戻りたくなる              |
|  4 | **C**       | I       | 家に戻る                  |

|  7 | **G/B**     | V       | Cへ戻りたがる               |

この曲は基本的に、**各小節で和声が変わる**構造です。しかも右手・左手で単純にコードをジャーンと弾くのではなく、コードを分解してアルペジオにしています。([GitHub][2])

# ① 1小節目 → 2小節目

### C → Dm7/C

まず1小節目。

**C = ド・ミ・ソ**

C長調の「I（1度）」です。

これは音楽でいう、

> **「ここが家ですよ」**

という感じ。

ところが2小節目で、

**Dm7/C = レ・ファ・ラ・ド**

になります。

ここで重要なのは、**左手の低い音がCのまま**ということ。

つまり、

**C → Dm7/C**

とコードの上側だけが動いています。

これによって、いきなり「遠くへ行った」という感じではなく、

> Cの場所にいながら、少し緊張感が生まれる

という効果があります。

---

# ② 2小節目 → 3小節目

### Dm7/C → G/B

ここが非常に勉強になります。

Dm7の構成音は、

**D・F・A・C**

です。

そしてGのコードは、

**G・B・D**

です。

つまり、

**Dm → G → C**

という流れができます。

これはC長調では、

**ii → V → I**

という超重要パターンです。

つまり、

> **Dm → G → C**

は、

> 「出発 → 緊張 → 帰宅」

のようなものです。

ジャズ、ポップス、クラシックなど、非常に多くの音楽で登場します。

---

# ③ 3小節目 → 4小節目

### G/B → C

ここでようやく**Cに解決**します。

GはC長調の**V（5度）**。

そしてCは**I（1度）**。

つまり、

**V → I**

です。

これは音楽理論で最重要の「解決」です。

特にGの中にある**B（シ）**が、

**B → C**

と半音上がることで、

> 「Cに行きたい！」

という強い感覚が生まれます。

そして4小節目のCで落ち着きます。

---

# ④ 5小節目 → 6小節目

### Am/C → D7/C

ここが今回の質問のポイントです。

5小節目は、

**Am/C**

です。

Amは、

**A・C・E**

なので、C長調では**vi（6度）**。

ここで、

**C → Am**

と変化します。

CとAmは、

**C → E → G**

と

**A → C → E**

で、共通する音がたくさんあります。

だから非常になめらか。

---

そして6小節目。

**D7/C**

です。

D7の構成音は、

**D・F#・A・C**

です。

ここで突然**F#（ファ♯）**が出てきます。

「え？C長調なのにF♯？」

これがバッハの面白いところです。

---

# ⑤ なぜD7が出てくるの？

ここが一番覚えてほしいところです。

D7は、

**D → G**

へ進みたがるコードです。

つまり、

**D7 → G**

という関係。

GはC長調におけるV（5度）です。

だからD7は、

> **「Gに行くためのV」**

になります。

これを**セカンダリードミナント**といいます。

C長調の中では、

**G = V**

ですが、

そのGを一時的に「家」に見立てると、

**D7 = V/V**

となります。

つまり、

> **VのV**

です。

これが5〜7小節の非常に重要な流れです。

### Am → D7 → G

音楽的には、

**Am**
↓
「ちょっと動こう」

**D7**
↓
「Gに行こう！」

**G**
↓
「到着！」

という感じです。

---

# ⑥ 6 → 7小節目

### D7/C → G/B

ここは非常に美しいです。

**D7 → G**

という強い進行。

しかも低音が、

**C → B**

と半音下がります。

そして7小節目のG/B。

通常のGなら、

**G・B・D**

ですが、Bを低音にしています。

これが**G/B（Gの第1転回形）**。

バッハは単純に

**C → G → C**

と動かすのではなく、

**低音を滑らかに動かしている**

わけです。

---

# ⑦ 7 → 8小節目

### G/B → Cmaj7/B

ここも初心者には非常に面白いところです。

普通なら、

**G → C**

で「はい、解決！」

となります。

ところがバッハは、

**Cmaj7/B**

にします。

Cmaj7は、

**C・E・G・B**

です。

つまり、Cコードなのに**B（シ）**が残っています。

そのため、

> Cに戻ったけど、まだ完全に終わってない

という感じになります。

これが次の9小節目につながります。

---

# ⑧ 8 → 9小節目

### Cmaj7/B → Am7

ここで、

**C → Am**

に進みます。

CとAmは非常に近いコードです。

実は、

**C = C E G**

**Am = A C E**

なので、

**CとEが共通**

しています。

だから非常になめらか。

そしてAm7になることで、

**A・C・E・G**

となり、さらにGも加わります。

---

# ⑨ 9 → 10小節目

### Am7 → D7

ここでまた、

**Am7 → D7**

となります。

そして次は……

**G**

へ行きたくなります。

つまり、

### 9 → 10 → 11小節

**Am7 → D7 → G**

です。

これがこの曲の大きな流れです。実際、11小節目でGのドミナントがしっかり現れ、ここまでのD7などの緊張が一つの到達点になります。([Music: Practice & Theory Stack Exchange][1])

初心者なら、ローマ数字を丸暗記するより、まずこれを覚えるといいです。

### 1〜4小節

**C → Dm → G → C**

↓

> **家 → 出発 → 緊張 → 家**

---

### 5〜8小節

**Am → D7 → G → C**

↓

> **家から少し離れる → Gへ行きたい → G到着 → Cへ戻る**

---

### 9〜11小節

**Am7 → D7 → G**

↓

> **また動き出す → Gへ行きたい → G到着**

## ⭐ そして、実は「ベース」を見るともっと面白い

1〜10小節の低音を見ると、

**C → C → B → C → C → C → B → B → A → C**

のように動きます。

単純なコード進行だけではなく、**転回形を使って低音を滑らかにしている**のがバッハのすごいところです。BWV 846は、単なるアルペジオではなく、複数の声部が滑らかに動く5声的な構造として分析されることもあります。([バッハ音楽学習ガイド][3])

# 🎯 あなたの「音階・コード勉強」という目的なら

この曲はかなりおすすめです。

ただし、**「C長調のコードを覚える教材」だけではありません。**

この10小節だけでも、

1. **C = I**
2. **Dm = ii**
3. **G = V**
4. **Am = vi**
5. **D7 = V/V**
6. **コードの転回形**
7. **セカンダリードミナント**
8. **V → Iの解決**

まで勉強できます。

特に、

> **C → Dm → G → C**

を自分で弾いて、その後

> **Am → D7 → G → C**

を弾いてみてください。

この2つの違いを耳で感じられるようになると、**「コード進行が分かる」という感覚がかなり身についてきます。**

そして次に進むなら、**11〜20小節が非常に面白いです。ここから「なぜC長調なのに♯や♭が出てくるのか」が分かってきます。**

## 教えてください、11〜20小節が非常に面白いです
はい。11〜20小節は、**「C長調の中で、どうやって遠くのコードへ移動していくのか」**を見るのにとても良い部分です。

ただ、まず大事な点があります。前回の説明ではコードを「1小節＝1コード」とかなり単純化しましたが、**バッハのプレリュードは1小節の中でも和声が変化する箇所があります**。11〜20小節では特にそれが重要です。

## 🎹 まず全体像

11〜20小節を大まかにコードで捉えると、次のような流れになります。

**G → C → A7 → Dm → G7 → C → F → G → C …**

つまり、

> **Cに戻る → また別の方向へ進む → Cに戻る**

という動きを繰り返しながら、少しずつ音楽を展開しています。

---

# ① 11小節目：G

10小節目で、

**Am7 → D7**

と来ました。

D7は「Gに行きたい」コードでしたね。

したがって、

**10小節目 D7 → 11小節目 G**

となります。

これは典型的な

**V/V → V**

です。

そしてGはC長調では**V（5度）**。

つまり、

> 「Gに着いた。でも本当の家はC」

という状態です。

---

# ② 11 → 12小節：G → C

そして、

**G → C**

と進みます。

これは、

**V → I**

です。

ここは非常に重要。

音楽の「緊張 → 解決」の基本形です。

ここまでで、

**Am → D7 → G → C**

という流れが完成します。

---

# ③ ところが、ここでまた動き始める

Cに戻ったので、

> 「これで終わりかな？」

と思わせます。

でもバッハは終わりません。

ここからまた次の目的地を作ります。

そこで登場するのが、

**A7**

です。

---

# ④ A7 → Dm

ここが11〜20小節で非常に勉強になるところです。

A7は、

**A・C♯・E・G**

というコード。

ここで、

### C♯（ド♯）

が登場します。

C長調には**C♯はありません**。

「なぜ突然C♯？」

という疑問が出ます。

答えは簡単で、

> **Dmへ行きたいから**

です。

A7は、

**D minor（Dm）**

のドミナントです。

つまり、

**A7 → Dm**

という関係。

---

# 🎯 これもセカンダリードミナント

C長調の中で、

**Dm = ii**

です。

そしてそのDmに対するドミナントが、

**A7**

です。

したがって、

**A7 = V/ii**

と考えられます。

これは前に出てきた

**D7 = V/V**

と同じ考え方です。

---

# ⑤ つまりバッハは「次の目的地」を作っている

ここまでを整理すると、

### 6小節目付近

**D7 → G**

↓

Gへ行きたい

### 11〜12小節付近

**G → C**

↓

Cへ帰る

### その後

**A7 → Dm**

↓

今度はDmへ行きたい

という具合です。

つまりバッハは、

> **「次にどこへ行きたいか」をドミナントで作っている**

わけです。

---

# ⑥ Dm → G7 → C

そしてDmに到着したら、今度は、

**Dm → G7 → C**

という流れを作れます。

これは、

**ii → V → I**

です。

C長調で最も重要なコード進行の一つです。

ここで、

**Dm → G7 → C**

を何度も弾いてみてください。

かなり「終わった」「帰ってきた」という感じがするはずです。

---

# ⑦ では、なぜA7のC♯が必要なのか？

ここはピアノで実際に弾くと非常に分かりやすいです。

まず、

**Dm → G → C**

を弾きます。

次に、

**A7 → Dm → G → C**

を弾きます。

A7の**C♯ → D**という動きを意識してください。

半音で、

**C♯ → D**

と上がります。

これが、

> 「Dmに行きたい！」

という強い力を作ります。

だからC長調の曲なのに、バッハはあえて**C♯**を入れるわけです。

---

# ⑧ これが「一時的に別の調にいる」感覚

ここがクラシック音楽を理解する上で面白いところです。

曲全体は**C長調**です。

でも一瞬、

**Dmを目的地**

として扱います。

さらにそのDmに向かって、

**A7**

を置く。

つまり、

> 「C長調の中で、一瞬だけDmを主役にする」

ということです。

これを**一時的な調性（tonicization）**として考えると分かりやすいです。

---

# ⑨ 15〜20小節あたりは「コードの連鎖」として聴く

この辺りでは、

**Dm → G → C**

という流れだけでなく、

**次のコードへ行くためのコード**

を次々に作っています。

初心者の段階では、全部をローマ数字で覚える必要はありません。

まず、

> **「このコードは、次のコードに行きたがっている」**

という感覚を身につけるのがおすすめです。

例えば、

**A7 → Dm**

なら、

> A7はDmに行きたがっている。

**D7 → G**

なら、

> D7はGに行きたがっている。

**G7 → C**

なら、

> G7はCに行きたがっている。

この3つを耳で覚えるだけでもかなり違います。

---

# 🎹 カノンとの違い

ここが、最初に話していた**パッヘルベルのカノン**との違いです。

カノンでは、

> **同じコード進行を繰り返すこと**

によって和声を体に覚えさせやすいです。

一方、バッハのプレリュードは、

> **「次のコードへ行きたい」という力を連続させる**

ことで音楽が進んでいきます。

だから、

### カノン

**I → V → vi → iii → IV → I → IV → V**

↓

「コード進行のパターンを覚える」

### バッハ

**Dm → G → C**
**A7 → Dm**
**D7 → G**

↓

「コード同士の関係を覚える」

という違いがあります。

---

# ⭐ 初心者なら、ここだけ練習してください

11〜20小節を全部弾く前に、まず次の4パターンを左手で弾いてみることをおすすめします。

### パターン①

**C → Dm → G → C**

### パターン②

**Am → D7 → G → C**

### パターン③

**A7 → Dm**

### パターン④

**Dm → G7 → C**

そして、

**「どのコードが次のコードへ行きたがっているのか？」**

を耳で感じてみてください。

これができるようになると、単に「楽譜に書いてある音を弾く」のではなく、**「この音楽は今どこへ向かっているのか」**が分かるようになります。

### そして、実は次の21〜30小節がさらに面白いです

ここまで来ると、バッハが**C長調から少しずつ遠くへ移動して、またC長調へ戻ってくる**構造が見えてきます。

もし「音階・コードを勉強する」という目的なら、**1〜35小節を「コード進行の地図」として見る**のがかなりおすすめです。
「C → Dm → G → C」だけでなく、**A7、D7、F7などの“本来C長調にはないコード”がなぜ出てくるのか**まで追うと、ポップスのコード進行も理解しやすくなります。

## 続きまして、次の21〜30小節も解説してください。
もちろんです。21〜30小節は、このプレリュードの中でも**一番「コード進行の勉強になる場所」**だと思います。

特にここでは、バッハが

> **「Gに行きたい」→「まだ行かせない」→「さらに緊張させる」→「やっとGに到着」**

ということをやっています。

前回までの「次のコードへ行きたがる」という考え方が、ここで一気に分かりやすくなります。

なお、BWV 846は基本的に**1小節ごとに和声が変化する**構造です。21〜35小節は、それまでの展開とは違って「終盤へ向けて緊張をどんどん蓄積する部分」です。([GitHub][1])

# ① 20 → 21小節

## C7 → F

ここからが本格的な展開です。

20小節目の重要なコードは、

**C7**

です。

普通のCではなく、

**C・E・G・Bb**

というC7。

ここで突然、

**Bb（シ♭）**

が出てきます。

「C長調なのにBb？」

と思いますよね。

これは、

> **Fへ行くため**

です。

C7はFに進みたがるコードです。

つまり、

**C7 → F**

です。

C長調におけるFは**IV（4度）**。

したがってC7は、

**V/IV**

つまり、

> **「Fというコードを一時的な目的地にするためのドミナント」**

です。([Music: Practice & Theory Stack Exchange][2])

---

# ② 21小節目：Fmaj7

そして21小節目で、

**Fmaj7**

に到着します。

つまり、

**C7 → Fmaj7**

で、

> 「Fに着いた！」

となります。

ここまでなら普通です。

ところが……

バッハはここで終わりません。

---

# ③ 21 → 22小節

## Fmaj7 → F#dim7

ここがものすごく面白い。

22小節目で、

**F#dim7**

が出てきます。

音は、

**F#・A・C・Eb**

です。

このコードの重要なポイントは、

### F# → G

という半音進行。

つまり、

> **Gへ行きたい！**

という力を持っています。

F#dim7は、Gに進むための**導音減七**として機能します。

ローマ数字では、

**vii°7/V**

と考えられます。

つまり、

> **「G（V）に行くための減七コード」**

です。([Oxford Learning Link][3])

---

# 🎯 ここで一度整理

20〜22小節は、

**C7 → F → F#dim7**

です。

目的地が、

**F → G**

と変わっています。

つまり、

> C7「Fへ行こう」
> ↓
> F「到着！」
> ↓
> F#dim7「今度はGへ行こう！」

です。

バッハは**目的地を次々に作っている**んです。

---

# ④ 22 → 23小節

## F#dim7 → Bdim7/Ab

ここからがさらにすごい。

普通なら、

**F#dim7 → G**

として、Gに行けばいい。

ところがバッハは、

> **「まだGに行かせません」**

とします。

23小節目に、

**Bdim7/Ab**

を置きます。

これも減七系の非常に不安定なコードです。

ここでは特に、

**Ab → G**

という半音下降が重要。

そして、

**B → C**

という半音上昇もあります。

つまり上下から、

**Ab → G**
**B → C**

と解決したくなる。

そのため、非常に強い緊張感が生まれます。([Music: Practice & Theory Stack Exchange][2])

---

# ⑤ 23 → 24小節

## Bdim7/Ab → G7

そしてついに、

**G7**

です。

ここでようやく、

> **「Gに着いた！」**

となります。

これが24小節目です。

ここまで、

**F → F#dim7 → Bdim7 → G7**

と、なんと**3段階かけてGに到達**しています。

これが21〜24小節の最大のポイントです。

---

# ⭐ 21〜24小節を物語として聴く

こう考えると分かりやすいです。

### 21

**F**

「ここに来た」

↓

### 22

**F#dim7**

「でも次はGへ行きたい」

↓

### 23

**Bdim7**

「まだ！もう一段階！」

↓

### 24

**G7**

「やっとG！」

これは音楽的には、**ドミナント（G）を到着点として、その到着を意図的に遅らせている**部分です。分析上も、22・23小節の2つの減七和音がGへの到達を準備していると説明されています。([Andrew Hennington][4])

---

# ⑥ 24 → 25小節

## G7 → C/G

ここで普通なら、

**G7 → C**

と完全に解決したくなります。

実際、Cのコードが出ます。

でも……

**C/G**

です。

つまり、

**Cコードなのに低音がG**

です。

これが非常に重要。

---

# 🎹 C/Gって何？

Cコードは、

**C・E・G**

です。

普通なら低音はC。

ところが、

**G・C・E・G**

のように、Gを低音にします。

これを**Cの第2転回形（I⁶⁴）**といいます。

だから、

> Cに戻ったように聞こえるけど、まだ完全には解決していない

という状態になります。

そして低音Gがそのまま残ります。

---

# ⑦ 24〜31小節は「Gの低音」がずっと続く

ここが、この曲の後半を理解する最大のポイントです。

24小節目から、

**Gを低音に置いた状態**

が長く続きます。

これを**ドミナント・ペダル**と呼びます。

つまり、

> **「Gをずっと鳴らしたまま、上のコードだけを変えていく」**

という仕組みです。

この区間は24〜31小節の**dominant pedal（属音ペダル）**として分析されています。([Andrew Hennington][4])

---

# ⑧ 25 → 26小節

## C/G → G7

25小節では、

**C/G**

で一瞬「Cかな？」と思わせます。

ところが26小節では、

**G7**

に戻ります。

つまり、

**C/G → G7**

です。

そしてまた、

> 「Cに戻りそうなのに、まだ戻らない」

という状態。

---

# ⑨ 26 → 27小節

## G7 → F#dim7/G

そして27小節。

また、

**F#dim7**

が出ます。

これは22小節と同じ考え方。

**F# → G**

という力を持っています。

ただし今回は低音が**G**。

つまり、

**F#dim7/G**

という非常に不安定な響きになります。

---

# ⑩ 28小節が特にすごい

28小節では、

**F#dim7/G**

のような非常に緊張した響きが現れます。

ここは、このプレリュードの中でも特に緊張感が高いところの一つです。

理由は、

### 低音

**G**

なのに、

### 上では

**F#・A・C・Eb**

という不安定な音が重なっているからです。

つまり、

> **「Gに到着しているようで、全然落ち着いていない」**

という状態。

---

# ⑪ 28 → 29小節

## 緊張 → C/G

そして29小節で、

**C/G**

に戻ります。

ここでもCなのに、

**低音はG**

です。

だから、

> 「Cに解決した！」

とはまだ言えません。

バッハは、**Cを見せながら、低音のGを離さない**。

---

# ⑫ 29 → 30小節

## C/G → G7

そして30小節。

再び、

**G7**

です。

つまり、

**C/G → G7**

となります。

ここまで来ると、

> 「いつになったらCにちゃんと帰るの？」

という気持ちになります。

これこそがバッハの狙いです。

---

# 🎯 21〜30小節を一気に見る

ここが一番重要です。

### 20〜24

**C7 → F → F#dim7 → Bdim7 → G7**

↓

**Fを目指す → Gを目指す → Gに到着**

---

### 24〜30

**G7 → C/G → G7 → F#dim7/G → C/G → G7**

↓

**Gを低音に固定**

↓

**Cに行きそう**

↓

**でもG7に戻る**

↓

**また緊張**

↓

**またCに行きそう**

↓

**またG7**

つまり、

> **「Cに帰りたいのに、Gが邪魔して帰れない」**

という状態を、バッハが長い時間かけて作っています。

---

# 🎹 そして31小節目へ

30小節まで来ると、

**G7**

の緊張が最大級になります。

そして31小節目でもG系の響きが続きます。

その後、32小節から今度は**Cを低音でずっと保持する「トニック・ペダル」**に変わります。

つまり、

### 24〜31

**Gペダル**

↓

「Cに帰りたい！」

### 32〜35

**Cペダル**

↓

「ようやく家に帰った！」

という構造です。([Andrew Hennington][4])

# ⭐ この曲の「すごさ」がここで分かります

最初の1〜10小節では、

**C → Dm → G → C**

という比較的分かりやすいコード進行でした。

ところが21〜30小節では、

**「目的地にすぐ行かない」**

という作曲技法が中心になります。

特に、

**F → F#dim7 → Bdim7 → G7**

そして

**G7 → C/G → G7 → F#dim7/G → C/G → G7**

を耳で覚えてください。

これが分かると、

> **「コード進行＝コードの名前を覚えること」ではなく、「コードが次のコードへ進みたがる力を聴くこと」**

だと実感できると思います。

そして、これは**ポップスのコード進行を理解する時にも非常に役立ちます**。

次は最後の**31〜35小節**を見ると、この「長く引っ張ったGの緊張が、どうやって最後のCに解決するのか」が分かります。ここはプレリュード全体のクライマックスです。

## 最後の31〜35小節も解説してください。

もちろんです。ここは**プレリュード全体の「帰宅」部分**です。

21〜30小節でバッハはずっと **G（属音）を低音に置いて、「Cに帰りたいのに、まだ帰れない」**という緊張を作りました。

31〜35小節では、それを一気に解決します。

## 🎹 31〜35小節の全体像

初心者向けに大きく捉えると、

**G → C/G → G7 → C**

という「最後のV → I」が中心です。

そして一番重要なのは、

> **31小節までGの緊張を引っ張り、32小節からCを低音にして、35小節で完全にCへ着地する**

という流れです。

---

# ① 31小節目：最後のGの緊張

30小節目まで、

**G**

が低音としてずっと存在していました。

31小節目も、その緊張感が続きます。

ここでのポイントは、

> **まだ「Cに完全に帰った」と感じさせない**

ことです。

つまり、

**V（G）**

の緊張がまだ残っています。

ここまで聴いてくると、耳はもう、

> 「そろそろCに戻ってくれ！」

という状態になっています。

これがバッハの狙いです。

---

# ② 32小節目：ついにCが低音になる

そして32小節。

ここで大きな変化が起きます。

低音が、

**G → C**

になります。

これが非常に重要です。

今までの

**Gを低音にしたC**

ではなく、

**Cを低音にしたC**

になります。

つまり、

### それまで

**C/G**

＝ Cコードだけど低音はG

### 32小節以降

**C**

＝ Cコード＋低音C

です。

これによって初めて、

> **「本当にCに帰ってきた！」**

という感覚になります。

---

# ③ 32〜35小節：Cのペダル

ここからの大きな特徴が、

**Cペダル**

です。

つまり、

> **低音のCを保ったまま、上の音を変化させる**

という構造です。

前半の

**Gペダル**

と完全に対照的です。

---

## 前半

**Gをずっと保持**

↓

「Cに帰りたい！」

---

## 最後

**Cをずっと保持**

↓

「もう帰ってきた！」

この対比がものすごく美しいです。

---

# ④ 「ペダル」って何？

ここは初心者にはぜひ覚えてほしい言葉です。

音楽理論でいう**ペダルポイント（pedal point）**とは、

> **低音の1つの音を長く保持し、その上で和音を変化させる技法**

です。

このプレリュードでは、

### 24〜31小節

**Gペダル**

### 32〜35小節

**Cペダル**

という大きな構造になっています。

つまり、

**G → C**

という、

> **ドミナント → トニック**

の関係そのものを、低音の動きで表現しています。

---

# ⑤ 33小節目：Cの上で少し動く

Cが低音に固定されたまま、右手の音が動いていきます。

ここで面白いのは、

> **低音がCなので、もう「帰宅」は成立している**

ということ。

でもバッハは、すぐに終わりません。

右手を動かしながら、

**Cの響きを少しずつ確認する**

ような時間を作ります。

これは、最初の1小節目のCと比べると非常に面白いです。

---

# ⑥ 1小節目と最後を比較してみる

このプレリュードは、

### 1小節目

**C**

から始まり、

### 35小節目

**C**

で終わります。

一見、

> 「Cで始まってCで終わっただけ」

に見えます。

でも、その間に、

**C → Dm → G → C**

から始まり、

**D7 → G**

や

**A7 → Dm**

などを経て、

さらに、

**Gペダル**

による巨大な緊張を作りました。

そして最後に、

**Cペダル**

へ移ります。

だから最後のCは、最初のCとは全然違って聞こえます。

---

# ⑦ 34〜35小節：完全な「帰宅」

最後の2小節は、

> **「もう終わるよ」**

という確認です。

低音Cが安定しているので、最初のような「次にどこへ行くの？」という不安がありません。

最後の和音は、

**C major**

です。

つまり、

**I（トニック）**

で完全に終わります。

# ⭐ ここが一番重要です

あなたが最初に言っていた、

> 「カノンはD長調なので、音階勉強に良い」

という視点から考えると、実はこのバッハのプレリュードは**さらに一歩進んだ教材**になります。

カノンでは、

**「コード進行の繰り返し」**

を勉強できます。

一方、このプレリュードでは、

### ① C長調の基本コード

**C / Dm / Em / F / G / Am**

↓

### ② V → I

**G → C**

↓

### ③ セカンダリードミナント

**D7 → G**

**A7 → Dm**

**C7 → F**

↓

### ④ 減七コード

**F#dim7 → G**

↓

### ⑤ 転回形

**C/G**

↓

### ⑥ ペダル

**Gペダル → Cペダル**

というところまで、一曲で体験できます。

## 🎹 私なら、初心者にはこう練習させます

いきなり原曲を弾きこなそうとするのではなく、まず左手だけで、

**C → Dm → G → C**

を弾く。

次に、

**Am → D7 → G → C**

を弾く。

次に、

**A7 → Dm → G → C**

を弾く。

最後に、

**G → C**

を何度も弾きながら、

> 「GはCに帰りたがっている」

という感覚を耳で覚える。

これができてから原曲を弾くと、**右手のアルペジオが単なる「ドミソドミソ……」ではなく、「コード進行を分解して弾いている」ように聞こえてきます。**

そして、これはかなり重要なのですが、**このプレリュードをC長調の教材として使うなら、次のステップは「各小節の右手の音を、C・Dm・Gなどのコード構成音に分類する練習」です。**

これをやると、**楽譜を見た瞬間に「この小節はCコードだ」と読めるようになる**ので、音階・コード・楽譜が一気につながります。
