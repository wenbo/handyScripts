## Preposition（プレポジション）は日本語で前置詞といいます。

前置詞の役割
前置詞は、名詞や代名詞の前に置かれ、時間、場所、方向、手段、原因などを表す言葉です。文中の他の単語との関係性を示す重要な役割を担います。

日本語には厳密な意味での「前置詞」は存在せず、同様の役割は「助詞」（例: ～に、～へ、～から）が担います。前置詞と助詞は、単語の位置関係が逆になるため、学習する際に注意が必要です。

## 介词（Preposition） 是用来表示名词、代词或名词短语与句中其他词之间关系的词。
它通常放在名词或代词前面，构成 介词短语，用来说明时间、地点、方向、原因、方式等。

## fer 来源于拉丁语动词 ferre，意思是： “携带、带来、承受、产生”
| 单词           | 词根分析                   | 含义       |
| ------------ | ---------------------- | -------- |
| **transfer** | trans（穿过、越过） + fer（带来） | 转移，搬运    |
| **refer**    | re（回） + fer（带来）        | 提到，参考，引用 |
| **offer**    | of（向前） + fer（带来）       | 提供，给予    |
| **fertile**  | fer（产生） + -ile（形容词后缀）  | 多产的，肥沃的  |
| **confer**   | con（一起） + fer（带来）      | 授予，协商，商议 |
| **infer**    | in（向内） + fer（带来）       | 推断，得出结论  |
